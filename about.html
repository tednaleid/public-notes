How this site works

Each page here is a self-contained HTML document written from research, experiments, or source material, and published on push.

Contents last updated 2026-10-03

  1. Pages
  2. Publishing

01 Pages

The hub lists every topic. A topic with several pages gets its own directory and a topic page that lists them. Each content page shows when its contents last changed, just under the title.

Source beside the page. Raw input that a page is written from, such as research output or release notes, is kept in the repo next to the page.

02 Publishing

A push to main scans for secrets, checks freshness stamps, and publishes the HTML, styles, and images. Markdown sources and scripts stay in the repo and are not published.
